# 前端 UI 优化设计文档

## 1. 项目背景

Ghost Flow Work App 前端当前使用 React 19 + TypeScript + Ant Design 6 构建，页面功能完整但视觉层次、间距和组件组合偏基础，距离专业 SaaS 管理后台有一定差距。

本次优化目标：

- 在不引入新 UI 框架依赖的前提下，基于 Ant Design 6 深度优化。
- 统一页面标题、内容布局和视觉风格。
- 提升信息密度、可读性和操作效率。
- 让整体界面更符合现代 SaaS 产品审美。

---

## 2. 设计策略

- **框架**：继续使用 Ant Design 6。
- **风格**：现代 SaaS 浅色风格。
- **改动范围**：中。
- **风险**：低，不引入新依赖，仅重构布局与样式。

---

## 3. 全局布局与视觉系统

### 3.1 整体结构

```
┌─────────────────────────────────────────────────────────────┐
│  Logo      仪表盘 / 任务管理                    版本 v0.1  🔃  │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                   │
│  侧边栏   │                 内容区 (24px padding)             │
│  导航     │                                                   │

│          │   │ 页面标题                    [新建按钮]  │    │
│          │   ├─────────────────────────────────────────┤    │
│          │   │                                         │    │
│          │   │              卡片 / 表格 内容            │    │
│          │   │                                         │    │
│          │   └─────────────────────────────────────────┘    │
│          │                                                   │
└──────────┴──────────────────────────────────────────────────┘
```

### 3.2 顶部 Header

- **背景**：`#ffffff`
- **高度**：64px
- **底部边框**：1px solid `#f0f0f0`
- **左侧**：当前页面标题（18px, font-weight 600）+ 面包屑
- **右侧**：系统版本、全局刷新按钮、用户头像占位
- 去掉现有渐变背景，改为干净的专业 SaaS 风格

### 3.3 侧边栏

- **宽度**：220px（折叠时 80px）
- **背景**：`#001529`
- **Logo 区**：高度 64px，白色文字 + 品牌图标，底部加 1px 分隔线
- **菜单**：
  - 选中项：左侧 3px 主色竖线 + 浅蓝背景
  - 悬停：背景色微亮
  - 图标与文字间距统一

### 3.4 内容区

- **背景**：`#f5f7fa`
- **内边距**：24px
- **页面标题区**：每个页面顶部统一放标题 + 操作按钮
- **卡片**：
  - 背景：`#ffffff`
  - 圆角：12px
  - 阴影：`0 1px 2px rgba(0,0,0,0.06)`
  - 标题区：16px 字体，底部 1px 分隔线（可选）

### 3.5 色彩系统

| 用途 | 颜色 |
|---|---|
| 主色 | `#1677ff` |
| 成功 | `#52c41a` |
| 警告 | `#faad14` |
| 错误 | `#ff4d4f` |
| 文字主色 | `#262626` |
| 文字次色 | `#595959` |
| 边框/分隔 | `#f0f0f0` |
| 页面背景 | `#f5f7fa` |

### 3.6 通用组件规范

- **按钮**：
  - 主操作：`type="primary"`，带图标
  - 次要操作：`type="default"` 或图标按钮
  - 危险操作：`danger`，仅在删除确认场景
- **表格**：
  - 表头：灰色背景 `#fafafa`，字体 14px 加粗
  - 行高：48px
  - 操作列：图标 + Tooltip，减少文字按钮堆砌
- **状态标签**：统一用 `Tag` + 颜色，文字简洁
- **空状态**：使用 `Empty` 组件，配清晰引导文案
- **加载**：表格和卡片统一使用 `loading` 属性

## 4. 页面详细设计

### 4.1 仪表盘（Dashboard）

**页面标题**：仪表盘  
**右侧操作**：刷新按钮

#### 布局

```text
┌──────────────────────────────────────────────────────────────┐
│  数据库连接        任务总数         成功执行         失败执行   │
│  ┌────┐  12       ┌────┐  8        ┌────┐  45      ┌────┐ 3   │
│  │ 🔗 │            │ 📄 │           │ ✅ │          │ ❌ │    │
│  └────┘            └────┘           └────┘          └────┘    │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────┐  ┌───────────────────────────────┐
│  调度引擎状态              │  │  最近运行记录（Top 5）         │
│  ● 运行中                  │  │  #102  任务A   成功  10:23    │
│  活跃定时任务：3           │  │  #101  任务B   失败  10:15    │
│                            │  │  #100  任务C   成功  09:50    │
│  [查看调度配置]            │  │  [查看全部历史]               │
└──────────────────────────┘  └───────────────────────────────┘
```

#### 改动点

- **统计卡**：4 列等宽，大屏下 `span={6}`；每张卡左侧放圆形图标底色；数字 28px 加粗；标签 14px 次要色；悬停轻微上浮 + 阴影加深。
- **调度状态卡**：单独成卡，左侧 Badge 状态，右侧放“活跃任务数”，底部增加快捷入口“查看调度配置”。
- **最近运行记录**：新增卡片展示最近 5 条运行记录；每条显示 Run ID、任务名、状态标签、执行时间；底部“查看全部历史”链接跳转。

### 4.2 连接管理（Connections）

**页面标题**：连接管理  
**右侧操作**：`[+ 新建连接]` 主按钮

#### 布局

```text
┌──────────────────────────────────────────────────────────────┐
│  连接管理                                    [+ 新建连接]     │
├──────────────────────────────────────────────────────────────┤
│  [搜索连接名称...]                                          │
├──────────────────────────────────────────────────────────────┤
│  ID │ 名称      │ 类型        │ 配置摘要      │ 操作        │
│  1  │ 生产库    │ SQLite      │ /data/...    │ 👁️ ✏️ 🗑️  │
│  2  │ Redshift  │ Redshift    │ host: ***    │ 👁️ ✏️ 🗑️  │
└──────────────────────────────────────────────────────────────┘
```

#### 改动点

- **搜索栏**：标题卡片下方增加搜索输入框，实时过滤名称。
- **类型标签**：SQLite 用 `green`，Redshift 用 `blue`。
- **配置摘要**：
  - SQLite：显示 `file_path` 路径，超长省略。
  - Redshift：显示 `host` 或 `database`，隐藏敏感信息。
  - 不再直接展示 JSON 字符串。
- **操作列**：查看详情、编辑、删除均使用图标按钮 + Tooltip。
- **新建/编辑弹窗**：表单字段分组（基础信息、认证配置），底部固定操作按钮。

---

### 4.3 任务管理（Tasks）

**页面标题**：任务管理  
**右侧操作**：`[+ 新建任务]` 主按钮

#### 布局

```text
┌────────────────────────────────────────────────────────────────────────┐
│  任务管理                                                [+ 新建任务]   │
├────────────────────────────────────────────────────────────────────────┤
│  [搜索任务名称/代码...]  [按标签筛选 ▼]  [类型 ▼]  [状态 ▼]             │
├────────────────────────────────────────────────────────────────────────┤
│  名称       │ 类型 │ 标签      │ 前置 │ 调度  │ 操作                    │
│  每日报表   │ SQL  │ 日报,BI   │ 无   │ 启用  │ ▶️ 👁️ ⬇️ ✏️ 🗑️        │
│  数据清洗   │ Py   │ ETL       │ #1   │ 停用  │ ▶️ ✏️ 🗑️              │
└────────────────────────────────────────────────────────────────────────┘
```

#### 改动点

- **筛选栏**：搜索框 + 标签多选 + 类型筛选 + 调度状态筛选。
- **表格列优化**：
  - 移除单独 ID 列（折叠到名称前作为 `#1` 小标签）。
  - 名称列加宽，支持 ellipsis。
  - 标签用多 Tag 展示，最多 2 行，超出 Tooltip。
  - 前置任务显示为可点击小标签。
  - 调度列：Switch + 状态 Tag 组合。
- **操作列**：运行、预览（SQL）、导出/下载（SQL）、编辑、删除，全部使用图标按钮 + Tooltip。
- **执行结果弹窗**：顶部状态大标签；错误信息用 Alert；SQL 结果用卡片包裹 DataPreview；Python 输出用 Code 样式块，stderr 红色。
- **新建/编辑任务弹窗**：分组或分步骤；连接选择为空时提示；Cron 表达式输入带常见示例。

### 4.4 调度配置（Schedules）

**页面标题**：调度配置  
**右侧操作**：刷新按钮

#### 布局

```text
┌──────────────────────────────────────────────────────────────┐
│  调度引擎状态                                                │
│  ● 运行中    活跃定时任务：3    下次触发：2026-07-13 09:00   │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│  排程任务列表                                                │
│  ID │ 任务名称  │ 类型 │ Cron        │ 下次执行     │ 操作   │
│  1  │ 每日报表  │ SQL  │ 0 9 * * *   │ 明天 09:00   │ 开关   │
│  2  │ 数据清洗  │ Py   │ 0 */6 * * * │ 18:00        │ 开关   │
└──────────────────────────────────────────────────────────────┘
```

#### 改动点

- **引擎状态卡**：大字号 Badge + 状态文字；三列信息（运行状态、活跃任务数、最近/下次触发时间）；提示文案说明调度任务在“任务管理”中配置。
- **任务列表**：表格展示所有带 `schedule_config` 的任务；Cron 表达式用 `Tag` + 等宽字体；下次执行时间格式化为“相对时间 + 绝对时间”；操作列只保留启用/停用 Switch。
- **空状态**：提示用户前往任务管理页面配置 Cron 表达式。

### 4.5 运行历史（History）

**页面标题**：运行历史  
**右侧操作**：刷新按钮

#### 布局

```text
┌──────────────────────────────────────────────────────────────┐
│  运行历史                                       [刷新] [筛选] │
├──────────────────────────────────────────────────────────────┤
│  [按任务筛选 ▼]  [状态 ▼]  [时间范围 ▼]                       │
├──────────────────────────────────────────────────────────────┤
│  Run ID │ 任务      │ 状态 │ 行数 │ 开始时间      │ 耗时    │
│  #102   │ 每日报表  │ 成功 │ 120  │ 07-12 10:23   │ 2.3s    │
│  #101   │ 数据清洗  │ 失败 │ -    │ 07-12 10:15   │ 5.1s    │
└──────────────────────────────────────────────────────────────┘
```

#### 改动点

- **筛选栏**：按任务筛选、按状态筛选、时间范围筛选（近 24h / 7天 / 30天 / 全部）。
- **表格列优化**：
  - Run ID：`Text code` + 复制按钮。
  - 任务列：显示 `#ID 任务名`。
  - 状态：彩色 Tag。
  - 行数：数字右对齐。
  - 开始时间：简化格式 `MM-DD HH:mm`。
  - 新增“耗时”列（结束时间 - 开始时间）。
- **展开详情**：只保留关键信息（错误详情、结果预览）；结果预览使用折叠面板或 Tab；错误信息完整显示且可复制。
- **分页**：保留底部分页，增加 `showTotal`。

## 5. 样式组织

- 继续使用 `frontend/src/index.css` 作为全局样式入口。
- 将通用工具类保留并扩展：
  - `.ghost-page-header`：页面标题区样式
  - `.ghost-card`：统一卡片样式
  - `.ghost-stat-card`：统计卡片样式
  - `.ghost-table-actions`：表格操作按钮组样式
  - `.ghost-filter-bar`：筛选栏样式
- 不再新增 CSS Modules 或 Tailwind，保持项目简洁。

---

## 6. 边界与范围

### 包含

- `AppLayout.tsx` 重构（Header、Sider、Content 视觉升级）。
- 五个页面组件的 UI 重构：Dashboard、Connections、Tasks、Schedules、History。
- 公共样式类扩展。

### 不包含

- 新增第三方 UI 框架或组件库。
- 后端 API 改动。
- 新增页面路由或功能（如用户系统、主题切换）。
- 移动端响应式深度适配（仅保留基础折叠和横向滚动）。
